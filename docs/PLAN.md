## Phase 1 — 메인 화면

> 세부 설계: [design/phase1-main-screen.md](design/phase1-main-screen.md)

게임을 처음 실행했을 때 보이는 화면입니다.

**확인 항목**
- "PANG" 타이틀이 화면에 표시된다
- GAME START / HOW TO PLAY 메뉴가 보이고 방향키로 선택할 수 있다
- GAME START 선택 시 게임 화면으로 넘어간다
- HOW TO PLAY 선택 시 조작 안내 화면이 표시된다
- 조작 안내 화면에서 확인 후 메인 화면으로 돌아온다
- 게임 중 ESC를 누르면 게임이 정지되고 메인 복귀 확인 메시지가 표시된다
- 확인 메시지에서 YES를 선택하면 메인 화면으로 돌아간다
- 확인 메시지에서 NO를 선택하면 게임이 재개된다

---

## Phase 2 — 플레이어 조작

> 세부 설계: [design/phase2-player.md](design/phase2-player.md)

캐릭터를 움직이고 와이어를 발사하는 기본 조작입니다.

**확인 항목**
- 좌우 방향키로 캐릭터가 좌우로 이동한다
- 화면 끝(벽)에서 더 이상 이동하지 않는다
- 스페이스바를 누르면 위쪽으로 와이어가 발사된다
- 와이어가 이미 발사 중이면 추가 발사되지 않는다
- 와이어가 천장이나 벽에 닿으면 사라진다

---

## Phase 3 — 버블 동작

버블이 튀어다니고 와이어에 맞아 분열하는 핵심 메커니즘입니다.

**확인 항목**
- 버블이 바닥과 벽에서 튀어 반사된다
- 버블이 중력을 받아 포물선으로 움직인다
- 와이어에 맞으면 버블이 더 작은 2개로 분열되어 좌우로 퍼진다
- 가장 작은 버블(Lv.1)은 와이어에 맞으면 사라진다

---

## Phase 4 — 게임 판정

플레이 중 발생하는 성공·실패 조건입니다.

**확인 항목**
- 버블이 캐릭터에 닿으면 게임 오버 화면이 표시된다
- 게임 오버 화면에서 Enter를 누르면 메인 화면으로 돌아간다
- 스테이지의 모든 버블을 제거하면 다음 스테이지로 넘어간다
---

## Phase 5 — 스테이지 구성 (Mission 1)

Mission 1의 3개 스테이지가 순서대로 진행됩니다.

**확인 항목**
- Stage 1-1: 버블 1개(큰 것)로 시작하며 지형이 없다
- Stage 1-2: 버블 2개가 등장하고 좌우에 벽이 추가된다
- Stage 1-3: 가장 큰 버블을 포함한 2개가 등장하고 벽이 3개로 늘어난다
- 1-1 → 1-2 → 1-3 순서로 자동 진행된다
- 1-3 클리어 시 Mission 1 완료 화면이 표시된다
