# PANG 게임 PRD — Mission 1

## 게임 개요

- **원작**: PANG
- **장르**: 아케이드 액션
- **플레이어**: 1인

---

## 핵심 게임플레이

| 요소 | 내용 |
|------|------|
| 목표 | 스테이지에 등장하는 모든 공을 제거 |
| 조작 | 좌우 이동, 사다리 오르내리기 (점프 없음) |
| 무기 | 위쪽으로 발사되는 와이어 |
| 사망 조건 | 공에 접촉 |
| 클리어 조건 | 모든 공을 최소 크기까지 분열·소멸 |

---

## 공(Bubble) 메커니즘

- 공은 바닥과 벽에서 튀어 다니며 포물선 운동
- 와이어에 맞으면 **더 작은 2개의 공으로 분열**
- 크기 단계: **5단계** (Lv.5 가장 큼 → Lv.1 가장 작음)
- Lv.1 공은 타격 시 완전 소멸 (분열 없음)
- 작은 공일수록 지면에 가깝게 이동

```
Lv.5 → Lv.4 × 2 → Lv.3 × 4 → Lv.2 × 8 → Lv.1 × 16 → 소멸
```
