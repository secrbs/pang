## 화면 구성

```
┌─────────────────────────────────────┐
│                                     │
│                                     │
│                                     │
│                                     │
│                                     │
│─────────────────────────────────────│  ← 바닥
│            [플레이어]                │
│    ↑ 와이어 (Space로 발사)           │
└─────────────────────────────────────┘
```

- 캔버스 크기: **800 × 600** (px)
- 플레이어는 바닥 위에서 좌우 이동
- 와이어는 플레이어 위치에서 수직으로 발사되어 천장까지 뻗음

---

## 컴포넌트 구조

```
App.tsx
  └─ GameScene.tsx          # 캔버스 및 게임 루프 관리
       ├─ useGameLoop.ts     # requestAnimationFrame 루프
       ├─ usePlayer.ts       # 플레이어·와이어 상태 및 입력 처리
       └─ <canvas>           # 플레이어·와이어 렌더링
```

## 상태

### 플레이어

| 상태 | 타입 | 초기값 | 설명 |
|------|------|--------|------|
| `x` | `number` | 캔버스 중앙 | 플레이어 X 좌표 |
| `y` | `number` | 바닥 고정 | 플레이어 Y 좌표 |
| `width` | `number` | `32` | 플레이어 너비 |
| `height` | `number` | `48` | 플레이어 높이 |
| `speed` | `number` | `4` | 프레임당 이동 거리 (px) |

### 와이어

| 상태 | 타입 | 초기값 | 설명 |
|------|------|--------|------|
| `active` | `boolean` | `false` | 발사 여부 |
| `x` | `number` | - | 발사 시 플레이어 중앙 X |
| `y` | `number` | - | 발사 시 플레이어 상단 Y |
| `speed` | `number` | `12` | 프레임당 상승 거리 (px) |

---

## 입력 처리

| 키 | 동작 |
|----|------|
| `ArrowLeft` | 플레이어를 왼쪽으로 이동 |
| `ArrowRight` | 플레이어를 오른쪽으로 이동 |
| `Space` | 와이어 발사 (active === false일 때만) |

- 키 입력은 `keydown` / `keyup` 이벤트로 눌린 키를 Set으로 관리
- 매 프레임 눌린 키 Set을 읽어 이동 처리 (부드러운 이동)

---

## 경계 처리

| 조건 | 처리 |
|------|------|
| 플레이어 왼쪽 끝 도달 (`x < 0`) | x를 0으로 고정 |
| 플레이어 오른쪽 끝 도달 (`x + width > 캔버스 너비`) | x를 `캔버스 너비 - width`로 고정 |
| 와이어가 천장 도달 (`y <= 0`) | 와이어 소멸 (`active = false`) |

---

## 와이어 동작 흐름

```
Space 입력
  → active === false 확인
  → wire.x = player.x + player.width / 2
  → wire.y = player.y
  → active = true

매 프레임
  → wire.y -= wire.speed
  → wire.y <= 0 → active = false (소멸)
```

## 렌더링 명세

### 플레이어
- 사각형으로 표현 (추후 스프라이트 교체 가능)
- 색상: `#00ccff`
- 크기: `width × height`

### 와이어
- 플레이어 중앙 X에서 수직으로 그린 선
- `wire.y` ~ `player.y` 구간
- 색상: `#ffffff`, 두께: `2px`

## 구현 순서

1. `GameScene.tsx` 생성 — Canvas 렌더링 기반 게임 화면
2. `useGameLoop.ts` 생성 — `requestAnimationFrame` 루프
3. `usePlayer.ts` 생성 — 플레이어·와이어 상태, 키 입력 처리
4. 플레이어 좌우 이동 및 경계 처리
5. 와이어 발사 및 천장 도달 시 소멸 처리
6. Canvas에 플레이어·와이어 렌더링
