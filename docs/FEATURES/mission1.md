# Mission 1 — 게임 난이도 및 규칙

## 개요

| 항목 | 내용 |
|------|------|
| 스테이지 수 | 3개 (Stage 1 → 2 → 3 순서 진행) |
| 난이도 | 입문 (Tutorial 수준) |
| 목적 | 기본 조작 및 공 분열 메커니즘 학습 |

---

## 스테이지 구성

### Stage 1-1 (낮)

- **공 구성**: Lv.4 공 × 1
- **지형**: 벽만 존재하는 단순 구조 (발판·사다리 없음)
- **특징**: 가장 단순한 구성으로 조작 방법 숙지 목적

```
┌─────────────────────────────────────┐
│                                     │
│         ●  (Lv.4 공)               │
│                                     │
│                                     │
│                                     │
│─────────────────────────────────────│
│  [플레이어]                          │
└─────────────────────────────────────┘
```

---

### Stage 1-2 (저녁)

- **공 구성**: Lv.4 공 × 1, Lv.3 공 × 1
- **지형**: 좌우에 낮은 벽(플랫폼) 추가
- **특징**: 복수의 공 동시 처리 연습

```
┌─────────────────────────────────────┐
│                                     │
│    ●  (Lv.4)       ●  (Lv.3)      │
│                                     │
│  [벽]                   [벽]        │
│                                     │
│─────────────────────────────────────│
│  [플레이어]                          │
└─────────────────────────────────────┘
```

---

### Stage 1-3 (밤) — 미션 최종

- **공 구성**: Lv.5 공 × 1, Lv.3 공 × 1
- **지형**: 중앙에 벽 추가
- **특징**: Mission 1 보스급 구성, Lv.5 공의 높은 바운스에 유의

```
┌─────────────────────────────────────┐
│                                     │
│  ●  (Lv.5)                         │
│                                     │
│  [벽]       [벽]       [벽]         │
│                    ●  (Lv.3)       │
│─────────────────────────────────────│
│  [플레이어]                          │
└─────────────────────────────────────┘
```

---

## 공 분열 시나리오 (Stage 1-1 기준)

```
Lv.4 공 1개
  └─ 와이어 타격
       ├─ Lv.3 × 2
       │    ├─ Lv.2 × 2  (각각)
       │    │    └─ Lv.1 × 2  (각각)  → 소멸
       │    └─ Lv.2 × 2
       │         └─ Lv.1 × 2  → 소멸
       └─ (총 처리해야 할 최소 공 수: 8개)
```

---

## 난이도 설정

| 요소 | Mission 1 설정 |
|------|----------------|
| 공 이동 속도 | 느림 |
| 공 바운스 높이 | Lv.5: 화면 상단, Lv.3 이하: 중간 |
| 와이어 발사 속도 | 기본 |
