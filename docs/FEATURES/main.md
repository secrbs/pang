# 메인 화면 구성

## 화면 레이아웃

```
┌─────────────────────────────────────┐
│                                     │
│           P A N G                   │  ← 타이틀 로고
│                                     │
│         [ GAME START ]              │  ← 선택 커서
│         [ HOW TO PLAY ]             │
│                                     │
└─────────────────────────────────────┘
```

---

## 구성 요소

### 타이틀 로고
- 화면 상단 중앙에 "PANG" 텍스트 표시

### 메뉴 항목
| 항목 | 동작 |
|------|------|
| GAME START | 게임 시작 (Mission 1 Stage 1로 진입) |
| HOW TO PLAY | 조작 방법 및 규칙 안내 화면 이동 |

- 방향키(↑↓)로 항목 선택
- Enter 또는 스페이스바로 확인

---

## 화면 전환

```
메인 화면
  ├─ GAME START 선택 → Mission 1 Stage 1 진입
  └─ HOW TO PLAY 선택 → 조작 안내 화면 → (확인 후) 메인 화면 복귀
```

---

## 구현 범위

- [ ] 타이틀 텍스트 렌더링
- [ ] 메뉴 항목 렌더링 및 커서 이동
- [ ] Enter/Space 키 입력으로 화면 전환
