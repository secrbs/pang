# 게임 룰 상세

## 기본 규칙

- 스테이지에 등장하는 **모든 공을 제거**하면 클리어
- 공에 닿으면 **즉시 사망** → 게임 오버

---

## 플레이어

| 속성 | 내용 |
|------|------|
| 이동 | 좌우 이동 (방향키) |
| 무기 | 와이어 (위쪽으로 발사) |

- 와이어는 동시에 **1개만** 발사 가능
- 와이어가 천장, 벽, 공에 닿으면 사라짐

---

## 공(Bubble) 메커니즘

### 크기 단계 및 분열

| 레벨 | 크기 | 타격 결과 |
|------|------|-----------|
| Lv.5 | 가장 큼 | Lv.4 × 2 로 분열 |
| Lv.4 | 큼 | Lv.3 × 2 로 분열 |
| Lv.3 | 중간 | Lv.2 × 2 로 분열 |
| Lv.2 | 작음 | Lv.1 × 2 로 분열 |
| Lv.1 | 가장 작음 | 소멸 |

### 공의 움직임

- 바닥과 벽에서 반사하며 포물선 운동
- 중력의 영향을 받고, 튕길 때마다 같은 높이까지 올라감
- 와이어와 부딪히면 분열, 분열 시 두 공은 각각 좌우로 퍼짐

---

## 와이어 발사

- 발사 방향: **항상 위쪽 (수직)**
- 와이어는 천장까지 도달하거나 공에 맞으면 사라짐
- 와이어는 벽을 통과하지 못함
- 와이어가 발사 중인 동안 **추가 발사 불가**
- 공에 맞은 위치에서 분열 발생

---

## 게임 오버 & 재시작

- 사망 시 → 게임 오버
- 게임 오버 화면에서 Enter → 메인 화면으로 복귀

## 게임 중 메인 화면 복귀

- 게임 플레이 중 **ESC** 키를 누르면 게임이 일시 정지되고 확인 메시지가 표시됨
- 확인 메시지: "메인 화면으로 돌아가시겠습니까? [ YES ] [ NO ]"
- YES 선택 시 → 메인 화면으로 복귀 (진행 중인 스테이지는 저장되지 않음)
- NO 선택 시 → 게임 재개
- 확인 중에는 버블·와이어 등 모든 게임 요소가 정지됨

---

- [ ] 공-플레이어 충돌 감지 및 사망 처리
- [ ] 게임 오버 판정 및 화면 전환
